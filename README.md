# SQL Window Functions Project

## 📌 Objective

Demonstrate advanced SQL concepts using window functions.

## 🛠️ Tools Used

* SQL Server

## 📊 Concepts Covered

* ROW_NUMBER()
* RANK()
* DENSE_RANK()
* PARTITION BY
* LAG()
* LEAD()

## 📂 Structure

* dataset/ → Raw employee sales data
* analysis/ → Window function queries

## 📈 Use Cases

* Ranking employees by performance
* Department-wise analysis
* Comparing current vs previous values

## 🚀 Learnings

* Advanced SQL analytics
* Writing efficient queries
* Real-world business scenarios

## 📊 Business Use Cases

* Ranked employees based on sales performance using RANK()
* Identified department-wise top performers using PARTITION BY
* Compared current vs previous sales using LAG()
* Forecasted next values using LEAD()
* Calculated running totals for trend analysis
